## Description

Inspired by the daily operations at Student Affairs and Student Success departments, I have created a browser extension, CUNY Refiner, to add useful shortcuts and improve your overall experience with various websites and services hosted by the City University of New York.

This project is currently under development and will be updated periodically.

<p align="right">(<a href="#readme-top">back to top</a>)</p>

## Getting Started

**🛑 If you only want to download and use the extension in your browser, not code and debug it, you should scroll up and use [one of these "Install from ..." links](#readme-top) instead. 🛑**

To set up this project *locally* for development purposes, simply clone the repo with
```sh
   git clone https://github.com/popoway/cuny-refiner.git
```
Then follow these instructions: [Chrome](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world) and [Firefox](https://extensionworkshop.com/documentation/develop/temporary-installation-in-firefox/)
